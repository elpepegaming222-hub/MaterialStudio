# MaterialStudio
Usa UV de mesh para poner PBR o imagen abstracta.
MATERIAL STUDIO HTML

1. Ejecuta ABRIR_MATERIAL_STUDIO.bat.
2. Si tienes Python, inicia un servidor local automáticamente.
3. Si no tienes Python, abre index.html directamente.

CONTROLES:
- Clic: seleccionar una cara.
- G: pantalla completa + oculta UI; G otra vez vuelve.
- R no se usa; el giro automático tiene botón.
- Botón Guardar PNG: descarga el render.
- Arrastra una textura al área indicada para cargarla como Albedo.
(El Bat es Alternativo).
